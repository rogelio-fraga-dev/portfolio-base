Full Stack · Educação · Em Produção

Sistema de Aulas — Plataforma de Ensino em Produção

Plataforma que eu construí para dar aula e que hoje é usada por ~75 alunos em duas turmas do curso técnico. Nasceu de uma restrição real: as máquinas do laboratório são lentas e não dá para instalar nada nelas. Rodando no navegador, não exige instalação — e abre no celular, o que derruba a desculpa de não ter computador em casa. O aluno tem editor de código com prévia ao vivo, salvamento automático, quiz com ranking em tempo real e revisão do que errou. O recurso central é o painel-modelo: o código da aula fica ao lado e cada linha digitada corretamente some do painel, então o sistema sabe exatamente onde o aluno parou. O professor abre e fecha quizzes, acompanha o código de cada aluno e confere presença. Os prazos abrem e fecham sozinhos pelo calendário de cada turma.

Do lado da operação: 244 testes verdes, deploy automatizado em dois minutos por GitHub Actions com OIDC (nenhuma chave da AWS guardada) e SSM (porta 22 pode ficar fechada), com pg_dump antes de toda migração e trava de horário para não reiniciar a aplicação enquanto uma turma está digitando.

Spring Boot 3.4 Java 21 Thymeleaf PostgreSQL + Flyway Docker AWS EC2 GitHub Actions (OIDC/SSM) Nginx

WireArc3D — Trajetórias para Manufatura Aditiva (WAAM)

Aplicação desktop para geração de trajetórias otimizadas em manufatura aditiva por deposição a arco. O sistema lê um modelo STL, fatia a peça em camadas, agrupa os pontos, resolve um problema de caixeiro-viajante (TSP) para ordenar o percurso e exporta o G-code de fabricação, com visualização 3D interativa e aceleração por GPU. É um projeto de terceiros, para o qual passo a contribuir como desenvolvedor — a primeira frente é a interface desktop.

Python 3.12 PyQt5 PyVista CUDA / CuPy FastAPI TSP (LKH)
